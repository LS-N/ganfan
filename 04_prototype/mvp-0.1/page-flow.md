# MVP 0.1 页面流转图说明

## 用户主路径

```text
打开 App
→ 首页查看今日饮食状态
→ 点击“记录一餐”
→ 进入记录页
→ 选择餐次
→ 输入食物
→ 添加食物
→ 查看热量估算
→ 保存记录
→ 返回首页
→ 首页今日状态更新
```

## 页面节点

### 1. 首页 Home

目标：
让用户一眼知道今天吃得怎么样，以及下一步该怎么做。

可跳转：

- 点击“记录一餐” → 记录页
- 点击未记录餐次卡片 → 记录页
- 点击已记录餐次卡片 → 详情页
- 点击历史入口 → 历史页
- 点击我的入口 → 我的页

### 2. 记录页 Record

目标：
让用户快速完成一餐记录。

可跳转：

- 保存成功 → 首页
- 取消 / 返回 → 首页
- 点击食物项 → 当前页内编辑状态

### 3. 饮食详情页 Detail

目标：
查看单餐详情，包括食物、热量、营养结构和 AI 简评。

可跳转：

- 返回 → 首页 / 历史页
- 编辑 → 记录页
- 删除成功 → 首页 / 历史页

### 4. 历史页 History

目标：
查看过去饮食记录。

可跳转：

- 点击某餐记录 → 详情页
- 切换日期 → 当前页刷新列表

### 5. 我的页 Profile

目标：
设置基础资料和饮食目标。

可跳转：

- 修改目标 → 当前页内编辑
- 保存资料 → 当前页反馈成功

## 关键状态

每个核心页面必须设计：

- 默认状态
- 空状态
- loading 状态
- 错误状态
- 保存成功状态
