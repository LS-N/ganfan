# 干饭路线图

## MVP 0.0 工程入场

交付物：

- GitHub 仓库
- Expo 项目
- Android preview 包
- EAS Update preview channel
- CI 检查
- AGENTS.md
- 基础页面壳

验收：

- App 可在手机打开
- 修改文案后可通过 EAS Update 更新到手机
- Codex 可根据 Issue/任务修改代码并提交 PR
