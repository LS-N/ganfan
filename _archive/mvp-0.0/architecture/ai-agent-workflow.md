# AI Agent 协作流程

## 1. 目标

用户通过手机提出需求，由 AI 总控拆解为产品、设计、开发、测试、发布任务，再交给 Codex 执行代码变更。

## 2. 角色

### 用户

提出目标，确认关键决策。

### Jarvis

负责产品大脑：

- 判断目标
- 拆解任务
- 生成 PRD
- 生成 Codex 任务
- 审查结果
- 控制边界

### Codex

负责代码执行：

- 阅读 AGENTS.md
- 阅读 PRD
- 修改代码
- 创建 PR
- 运行测试
- 输出变更说明

### CI/CD

负责自动检查和更新发布：

- 类型检查
- Lint
- 测试
- EAS Update
- 构建包

## 3. 标准流程

```text
用户手机提出需求
→ Jarvis 判断任务类型
→ 生成 Issue / Codex Prompt
→ Codex 修改代码
→ 创建 PR
→ 自动测试
→ 合并到 dev
→ 触发 preview OTA
→ 用户手机打开 App 验证
→ 通过后合并 main / 发 production
```

## 4. 开发阶段铁律

先跑通工程流水线，再开发完整业务。

第一目标不是“做完干饭”，而是：

> 让 AI 修改一个页面文案后，你不用连电脑，也能在手机 App 里看到更新。
