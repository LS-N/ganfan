# MVP 0.1 任务拆解: 7 天身体拼图

## 前置条件

必须先完成 MVP 0.0 工程入场。

完整业务开发前必须完成：

- 原型确认
- PRD V1 确认
- 数据模型确认
- AI 输出 JSON Schema 确认
- 图片采集 / 上传方案确认
- Android / iOS 原生能力影响确认

## 任务组 A: 欢迎 / 定位与建档

- 欢迎 / 定位页
- 7 天实验价值表达
- 非医疗建议提示
- Profile 类型
- 建档表单
- 字段校验
- 建档保存状态

## 任务组 B: 标准拍照

- 标准拍照规则 UI
- 拍照 / 相册入口
- 图片预览
- 重拍流程
- 图片上传状态
- 图片清晰度 / 遮挡提示
- 原生权限与重新打包影响标记

## 任务组 C: AI 即时分析

- 实施前先阅读 `02_architecture/ai-meal-analysis-architecture.md`
- Analysis 类型
- AI 结构化输出 JSON Schema
- 主食 / 蛋白 / 蔬菜纤维 / 油脂负担范围判断
- 风险提示和轻建议
- 置信度提示
- 30 秒返回或兜底
- 分析失败可恢复状态

## 任务组 D: 饭后反馈

- Feedback 类型
- 饭后 60 分钟反馈入口
- 饱腹状态选择
- 身体感受多选
- 价格满意可选项
- 错过反馈补填状态
- 反馈完成后的即时小洞察

## 任务组 E: 单餐档案

- Meal 类型
- 餐食照片展示
- 结构分析展示
- 饭后反馈展示
- 风险提示展示
- 可选剩余量 / 空盘校准入口
- 无反馈 / 分析失败状态

## 任务组 F: 身体拼图报告

- Report 类型
- 有效餐次统计
- 数据不足状态
- 7 天规律
- 风险组合
- 安全食物
- 下周建议
- 报告生成失败兜底

## 任务组 G: 餐前抽卡雏形

- 安全牌
- 风险牌
- 采纳 / 跳过反馈
- 抽卡规则来源说明
- 无报告不可用状态
- 采纳率埋点预留

## 任务组 H: 数据层与服务

- 本地 mock 数据流
- 后续 Supabase 表结构预留
- 图片存储服务接口预留
- AI 分析服务接口预留
- 报告生成服务接口预留
- 不记录、不打印隐私数据

## 任务组 I: 测试与验收

- 页面渲染测试
- 建档字段校验测试
- 拍照状态测试
- AI 低置信度 / 失败兜底测试
- 饭后反馈状态测试
- 报告数据不足状态测试
- 非医疗和非精确热量文案检查

## MVP 0.1 指标验收

- 建档完成率 > 70%
- 饭前标准单拍完成率 > 80%
- 饭后 10 秒反馈完成率 > 60%
- 连续 7 天使用率 > 40%
- 身体拼图二次查看率 > 40%
- 餐前抽卡采纳率 > 30%
- 20 人测试中主动私信 / 分享用户数 >= 5 人
