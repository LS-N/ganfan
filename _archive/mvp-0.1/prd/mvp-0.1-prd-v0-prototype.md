# MVP 0.1 PRD V0: 7 天身体拼图原型驱动版

## 1. 状态

本文件用于生成和评审 MVP 0.1 原型，不直接进入 Coding。

MVP 0.1 的方向已调整为“7 天身体拼图验证”。

## 2. 版本目标

唯一目标：

> 验证用户是否愿意用“一张标准餐食照 + 饭后 10 秒反馈”，换取一周后的个人身体洞察。

本 MVP 不验证完整商业模式，不做配餐托管，不接硬件，不输出医疗建议。它只验证最底层数据闭环：

```text
用户愿意提供轻量数据
→ 系统能完成结构化分析
→ 用户愿意完成饭后反馈
→ 7 天后获得“它懂我”的身体拼图洞察
```

## 3. 核心用户与场景

| 用户 | 场景 | 核心痛点 | MVP 承诺 |
|---|---|---|---|
| 高频外卖白领 | 工作日午餐 | 吃完困、胀、后悔 | 找出哪种午饭正在偷走你的下午 |
| 独居年轻人 | 晚餐 / 周末 | 随便吃、吃贵了、不舒服 | 看清自己吃得舒服的规律 |
| 轻减脂人群 | 三餐 | 不想算热量 | 不算卡路里，也能知道结构是否过重 |

## 4. 产品原则

1. 前端极轻，后端极重：用户只做标准拍照和 10 秒反馈，识别、估算、校准、建模和洞察放在后端。
2. 第一阶段不展示精确卡路里，不承诺精确克数，不输出医学级结论。
3. 即时分析只做结构化范围判断：主食偏多 / 适中 / 偏少，蛋白质偏足 / 不足，蔬菜纤维不足，油脂负担偏高等。
4. 饭后不强制拍空盘；剩余量拍照只作为可选校准。
5. 所有页面和功能必须服务 7 天闭环，不服务闭环的功能先砍掉。
6. 反馈必须极短，默认不写长文本。

## 5. 页面范围

本版本包含：

1. 欢迎 / 定位页
2. 建档页
3. 标准拍照页
4. AI 即时分析页
5. 饭后反馈页
6. 单餐档案页
7. 身体拼图报告页
8. 餐前抽卡雏形

## 6. 不做范围

- 精确热量计算
- 复杂营养克数展示
- 医疗诊断或治疗建议
- 完整配餐托管
- 食谱商城
- 社区
- 付费体系
- 硬件接入
- 体检报告导入
- 运动管理

## 7. 用户主流程

```text
打开 App
→ 理解 7 天身体拼图价值
→ 完成基础建档
→ 饭前拍一张标准餐食照
→ 获取 AI 即时结构分析
→ 吃饭
→ 饭后 60 分钟完成 10 秒反馈
→ 生成单餐档案
→ 连续累计 7 天
→ 查看身体拼图报告
→ 使用餐前抽卡雏形做下一餐轻决策
```

可选增强流程：

```text
饭后拍剩余 / 空盘
→ 用于校准饭量
```

该动作不能成为必填项。

## 8. 页面目标

| 页面 | 目标 | 不做什么 |
|---|---|---|
| 欢迎 / 定位页 | 10 秒内让用户知道 7 天要做什么、能换来什么 | 不放复杂商业故事 |
| 建档页 | 收集最小必要信息，支持后续个性化判断 | 不收体检报告，不接硬件 |
| 标准拍照页 | 让用户 10 秒内理解并完成标准餐食照 | 不做双拍，不强制称重 |
| AI 即时分析页 | 输出结构判断、轻建议、可信提示 | 不显示精确卡路里 / 医学结论 |
| 饭后反馈页 | 快速记录撑 / 刚好 / 饿、舒服 / 胀 / 困 / 有精神 | 不要求长文本 |
| 单餐档案页 | 让用户看懂这一餐为什么被记录 | 不做复杂报表 |
| 身体拼图报告页 | 输出 7 天规律、风险组合、安全食物、下周建议 | 不做泛泛健康鸡汤 |
| 餐前抽卡雏形 | 用安全牌 / 风险牌给下一餐轻提示 | 不做完整餐单托管 |

## 9. AI 即时分析输出规范

| 模块 | 允许输出 | 禁止输出 |
|---|---|---|
| 结构判断 | 主食偏多 / 适中，蛋白质偏足 / 不足，蔬菜不足，油脂偏高 | 精确卡路里、精确克数、医学诊断 |
| 轻建议 | 先吃蛋白和菜，主食少吃几口，汤少喝 | 治疗建议、药物建议、极端节食 |
| 风险提示 | 这类组合可能让你饭后犯困，需要反馈验证 | 断言一定会犯困 / 会长胖 |
| 置信度 | 图片较清楚 / 存在遮挡，结果仅供参考 | 假装精确 |

## 10. 数据对象

| 对象 | 字段 | 说明 |
|---|---|---|
| Profile | 年龄 / 性别 / 身高 / 体重 / 目标 / 预算 / 忌口 / 口味 / 常见感受 | 只收最小必要字段，避免建档流失 |
| Meal | 餐次 / 时间 / 地点可选 / 图片 ID / 餐食类型 / 结构分析 / 风险提示 | 每餐一条主记录 |
| Analysis | 主食水平 / 蛋白水平 / 蔬菜纤维 / 油脂负担 / 饭量相对水平 / 置信度 | 全部范围化，不做精确热量承诺 |
| Feedback | 饱腹状态 / 舒服状态 / 困倦 / 胀气 / 有精神 / 价格满意可选 | 后端建模的核心燃料 |
| Report | 7 天规律 / 风险组合 / 安全食物 / 下周建议 / 餐前抽卡规则 | 由结构化数据生成，不靠空洞文案 |

## 11. 核心指标

| 指标 | 目标 |
|---|---|
| 建档完成率 | > 70% |
| 饭前标准单拍完成率 | > 80% |
| 饭后 10 秒反馈完成率 | > 60% |
| 连续 7 天使用率 | > 40% |
| 身体拼图二次查看率 | > 40% |
| 餐前抽卡采纳率 | > 30% |
| 主动私信 / 分享用户数 | 20 人测试中 >= 5 人 |
