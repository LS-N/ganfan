# Phase 1 / MVP 1.0 验收标准

来源：`docs/02-master-blueprint.md` 的 `MVP 1.0 — 记录感知`。

## 最终验收

- 完整走通：注册 -> 建档 -> 拍照 -> 分析 -> 反馈 -> 回访。
- 7 天连续记录后首页出现身体洞察。
- 断网可记录，联网后数据完整同步。
- Android 真机稳定运行 24 小时无崩溃。
- `meals` 表数据完整率 > 95%。

## Sprint 验收

| Sprint | 验收标准 |
|---|---|
| Sprint 1 | 能注册登录，能填写个人档案，数据同时写入 SQLite 和 Supabase，营养向量库已初始化 |
| Sprint 2 | 拍照 -> AI 分析 -> 看到结果 -> 保存，全流程 < 30 秒，数据完整写入 |
| Sprint 3 | 拍照 -> 分析 -> 即时反馈 -> 当天/次日回访，数据全链路完整 |
| Sprint 4 | 能找到任意历史餐次完整数据，体重有时序记录，档案可完整编辑 |
| Sprint 5 | 首页逻辑完整，推荐卡可用，7 天后出现首条身体洞察 |
| Sprint 6 | 离线、错误处理、性能、监控、EAS Build、内测分发完成 |

## 必跑检查

```powershell
npm run lint
npm run typecheck
npm test
```

涉及原生能力或 EAS 配置时，必须补充真机和构建验证。
