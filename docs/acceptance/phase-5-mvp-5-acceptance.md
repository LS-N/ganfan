# Phase 5 / MVP 5.0 用户履约验收清单

来源：`docs/02-master-blueprint.md` 第 2564-2622 行。

任何 Phase 5 任务结束前，必须逐条标记 `PASS` / `PARTIAL` / `FAIL` / `N/A`，并写入 `docs/TASK_LOG.md`。

## 最终验收

- [ ] 90 天回顾报告数据准确。
- [ ] 食材清单从计划正确生成。
- [ ] `community_dishes` 表有聚合数据。
- [ ] 新用户推荐标注“基于与你相似的用户”。

## 任务级验收

| 任务 | 验收项 |
|---|---|
| T20-01 | 有 90 天数据的账号报告准确展示精力、体重、肠胃、预测准确率趋势 |
| T21-01 | 5 菜计划生成正确食材清单和份量 |
| T22-01 | 沙盒环境下单流程完整，订单状态可追踪 |
| T23-01 | 配餐订阅流程完整，预览菜单、份数、配送时间可设置，数据写入 Supabase |

| T25-02 | 新注册用户推荐来自社区数据，并有数据来源标注 |
