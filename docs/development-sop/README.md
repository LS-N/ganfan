# 开发 SOP 方案库

本目录存放项目无关的 AI 协作开发标准流程。

## 当前最新方案

- `LATEST.md`：当前唯一生效的开发 SOP 方案。

## 更新规则

每次更新 `LATEST.md` 时，必须在文件顶部“更新记录”中追加：

- 更新时间。
- 更新人员。
- 更新背景。
- 更新内容。

更新后必须同步检查 `docs/00-INDEX.md` 是否仍指向当前最新方案。

## 使用边界

本目录定义“从需求到开发交付”的通用流程，不定义《干饭》的产品范围、字段、页面、算法或阶段任务。《干饭》的产品和工程范围仍以 `docs/02-master-blueprint.md` 为准。
