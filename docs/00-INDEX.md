## 推荐阅读顺序

1. `docs/01-current-phase.md`：当前阶段、禁止事项、下一步。
2. `AGENTS.md`：AI Agent 工作契约。
3. `docs/02-master-spec.md`：当前产品总纲。
4. `docs/03-phase-1-closed-loop.md`：Phase 1 产品闭环。
5. 当前任务相关文档。
