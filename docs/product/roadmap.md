# 干饭路线图

## MVP 0.0 工程入场

交付物：

- GitHub 仓库
- Expo 项目
- Android preview 包
- EAS Update preview channel
- CI 检查
- AGENTS.md
- 基础页面壳

验收：

- App 可在手机打开
- 修改文案后可通过 EAS Update 更新到手机
- Codex 可根据 Issue/任务修改代码并提交 PR

## MVP 0.1 7 天身体拼图验证

交付物：

- 欢迎 / 定位页
- 建档页
- 标准拍照页
- AI 即时分析页
- 饭后反馈页
- 单餐档案页
- 身体拼图报告页
- 餐前抽卡雏形
- 本地或云端测试数据保存

验收：

- 用户理解 7 天实验价值
- 用户能完成一张标准餐食照
- AI 只输出范围化结构分析，不输出精确卡路里或医学结论
- 用户能完成饭后 10 秒反馈
- 至少 5 条有效餐次后可生成基础身体拼图报告
