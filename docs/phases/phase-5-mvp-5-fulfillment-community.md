# Phase 5: MVP 5.0 用户履约

来源：`docs/02-master-blueprint.md` 的 `MVP 5.0 — 用户履约`。

## 阶段目标

在用户授权和信任建立后，支持食材采购、配餐订阅和社区数据反哺，形成从建议到履约的闭环。

## 前置条件

- 平台用户 >= 1000。
- 个人预测准确率 >= 0.65。
- 用户确认采购平台或配餐合作方案。

## Sprint 20: 信任证明

| 任务 | 开发目标 | 交付物 |
|---|---|---|
| T20-01 | 健康成果报告 | 90 天回顾报告，展示精力、体重、肠胃、预测准确率变化 |

## Sprint 21-22: 食材采购

| 任务 | 开发目标 | 交付物 |
|---|---|---|
| T21-01 | 食材清单从计划生成 | `plan_to_grocery_list(plan_id)` |
| T22-01 | 采购接口对接 | 第三方生鲜 API 沙盒对接、订单状态 |

## Sprint 23-24: 配餐订阅

| 任务 | 开发目标 | 交付物 |
|---|---|---|
| T23-01 | 配餐方案界面 | 菜单预览、份数、配送时间、订阅数据写入 |

## Sprint 25-26: 社区层

| 任务 | 开发目标 | 交付物 |
|---|---|---|
| T25-01 | CommunityDishProfile 聚合 | 每日聚合社区菜品表现，写入 `community_dishes` |
| T25-02 | 协同过滤推荐 | 新用户冷启动推荐，标注社区数据来源 |
