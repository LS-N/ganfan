# 资源与密钥索引

本目录记录项目依赖的外部资源、账号、密钥、token、测试设备、数据集和本机工具。

## 当前索引

- `RESOURCE_REGISTRY.md`：当前唯一资源索引。

## 安全规则

- 本目录只记录资源名称、用途、环境变量名、存放位置、提供方、状态和验证方式。
- 禁止记录真实密码、真实 token、真实 API key、真实 service role key、数据库密码或私钥。
- 真实值只能放在本机 `.env`、`services/ai/.env`、密码管理器、云平台 secrets 或用户明确指定的安全位置。
- 任何 AI 需要真实值时，只能提示用户把值放入指定位置，不能要求用户把真实密钥粘贴进文档或代码。

## 使用方式

任何真实联调、数据库迁移、AI provider、云资源、真机验收或数据导入开始前，先读取 `RESOURCE_REGISTRY.md`，确认：

- 需要哪些资源。
- 哪些资源由用户提供。
- 哪些资源 AI 可以准备。
- 真实值应该放在哪里。
- 怎么验证资源可用。
- 缺失资源时是否允许 mock 或降级。
