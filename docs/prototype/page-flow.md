# MVP 0.1 页面流转图说明

## 用户主路径

```text
打开 App
→ 欢迎 / 定位页理解 7 天身体拼图
→ 建档页完成基础资料
→ 标准拍照页拍一张餐食照
→ AI 即时分析页查看结构判断
→ 吃饭
→ 饭后 60 分钟进入反馈页
→ 完成 10 秒反馈
→ 查看单餐档案
→ 累计 7 天有效餐次
→ 查看身体拼图报告
→ 餐前抽卡获取安全牌 / 风险牌
```

## 可选增强路径

```text
单餐档案
→ 可选拍剩余 / 空盘
→ 校准饭量
```

该路径不能阻断主流程。

## 页面节点

### 1. 欢迎 / 定位页

目标：
让用户 10 秒内知道这个实验是什么、每天要做什么、7 天后能获得什么。

可跳转：

- 点击开始建档 → 建档页
- 已完成建档 → 标准拍照页 / 首页入口

### 2. 建档页

目标：
用最少字段建立个人判断上下文。

可跳转：

- 保存成功 → 标准拍照页
- 暂时跳过非必填项 → 当前页继续
- 保存失败 → 当前页展示可恢复错误

### 3. 标准拍照页

目标：
让用户完成一张可分析的标准餐食照。

可跳转：

- 拍照 / 选图成功 → 当前页预览
- 点击提交分析 → AI 即时分析页
- 图片不清楚 → 当前页提示重拍或继续
- 上传失败 → 当前页重试

### 4. AI 即时分析页

目标：
用范围化判断解释这一餐的结构和可能风险。

可跳转：

- 分析成功 → 单餐档案页 / 稍后反馈入口
- 低置信度 → 当前页展示可信提示，可继续
- 分析失败 → 当前页展示兜底，可重试或保存为待分析

### 5. 饭后反馈页

目标：
饭后 60 分钟内用 10 秒收集身体感受。

可跳转：

- 保存成功 → 单餐档案页
- 未到时间 → 当前页显示稍后提醒
- 错过反馈 → 当前页允许补填并标记 late

### 6. 单餐档案页

目标：
展示餐食照片、结构分析、饭后反馈和风险提示。

可跳转：

- 补反馈 → 饭后反馈页
- 可选饭量校准 → 标准拍照页的剩余量校准模式
- 返回 → 今日记录 / 报告入口

### 7. 身体拼图报告页

目标：
把 7 天数据变成个人规律、风险组合、安全食物和下周建议。

可跳转：

- 数据不足 → 标准拍照页继续记录
- 报告生成成功 → 餐前抽卡雏形
- 生成失败 → 当前页重试

### 8. 餐前抽卡雏形

目标：
在下一餐前给出安全牌 / 风险牌，让用户开始让渡一点饮食决策权。

可跳转：

- 采纳 → 记录采纳结果
- 跳过 → 返回主入口
- 无报告 → 身体拼图报告页 / 继续记录

## 关键状态

每个核心页面必须设计：

- 默认状态
- 空状态
- loading 状态
- 错误状态
- 成功状态

本 MVP 额外必须设计：

- 拍照引导 / 重拍 / 上传失败状态
- AI 分析加载 / 低置信度 / 失败兜底状态
- 饭后反馈未到时间 / 可反馈 / 已反馈 / 错过状态
- 报告数据不足 / 可生成 / 已生成 / 生成失败状态
