# 原型目录

本目录保存当前产品原型入口和仍有参考价值的原型说明。

## 当前有效文件

- `meal-agent-product-prototype.html`：唯一开发对标母版原型。修改前必须先备份现有原型历史到 `_archive/prototype-history/`，再更新主原型。
- `meal-agent-product-prototype-home-multi-meal-20260515.html`：首页多餐状态机对齐原型，用于确认 30 分钟主卡、当天未反馈提示、加餐独立记录和打卡日历定位；仅作对齐，不替代母版。
- `page-flow.md`：页面流转与核心路径。
- `prototype-assets.md`：原型图、设计稿、截图、Figma 链接记录。
- `confirmed-screens.md`：已确认页面说明。

## 使用规则

- 原型用于理解页面流转、关键状态和字段，不直接替代 `docs/02-master-blueprint.md` 或当前阶段开发文档。
- 历史原型备份已移到 `_archive/prototype-history/`。
- 在主原型和同步开发方案未定稿前，不进入 App 业务开发。
- 旧 MVP 0.1 PRD 已移到 `_archive/mvp-0.1/prd/`。
