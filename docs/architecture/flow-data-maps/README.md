# Phase 1 流程级数据图（Flow Data Maps）

本目录是干饭项目的「流程级数据图」库。每个用户流程一份独立 .md 文档，描述这个流程涉及的所有数据生产、归纳、消费动作。

## 目的

| 用途 | 说明 |
|---|---|
| 架构守门 | 任何新流程进入实施前，必须先输出本目录下对应的数据图 |
| 数据血缘 | 一眼看出某字段从哪个流程产生、被哪些流程消费 |
| 重构基线 | 改某层时知道会影响哪些流程 |
| 新人入门 | 接手者通过流程图理解产品的数据架构 |

## 强制规则（与 `AGENTS.md` 同步）

**任何新流程 / 新功能进入 L2 App 代码实施前，必须先输出本目录下对应的流程级数据图，并经用户确认。**

未输出数据图就开始写代码 = 违反架构纪律 = 必须打回。

## 文档结构（每份流程图必含）

1. **流程基本信息**：流程名、触发、涉及页面、用户耗时、入口/出口动作 ID
2. **四层泳道图**：USER / AI 生产 / Layer 1 / Layer 2 / Layer 3 五列表格，按时间步骤逐行
3. **数据血缘**：每个写入字段的来源 + 被哪些消费者使用
4. **触发条件**：进入这个流程的前置条件
5. **洞察影响**：read 哪些 insights / 写入后可能触发哪些 insights 变化
6. **架构检查清单**：对照三层架构原则做自检（[✓] [⚠] [✗]）
7. **变更记录**：每次修改记一条

详细模板见 `_template.md`。
