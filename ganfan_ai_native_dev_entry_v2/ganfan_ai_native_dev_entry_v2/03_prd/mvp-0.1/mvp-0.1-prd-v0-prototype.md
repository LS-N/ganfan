# MVP 0.1 PRD V0：原型驱动版

## 1. 状态

本文件用于生成原型，不直接进入 Coding。

## 2. 版本目标

完成饮食记录最小闭环：

```text
查看今日状态
→ 记录一餐
→ 保存饮食记录
→ 首页状态更新
```

## 3. 页面范围

本版本包含：

1. 首页
2. 记录页
3. 饮食详情页
4. 历史页
5. 我的页

## 4. 不做范围

- 社区
- 付费
- 运动
- 食谱商城
- 复杂营养课程
- 医疗诊断

## 5. 用户主流程

```text
打开 App
→ 查看今日饮食状态
→ 点击记录一餐
→ 输入食物
→ 保存
→ 返回首页
→ 今日状态更新
```

## 6. 页面目标

| 页面 | 目标 |
|---|---|
| 首页 | 让用户知道今天吃得怎么样，下一步该怎么吃 |
| 记录页 | 快速完成一餐记录 |
| 详情页 | 查看单餐详情 |
| 历史页 | 查看过去记录 |
| 我的页 | 设置基础资料与目标 |

## 7. 原型输出要求

需要输出：

1. 首页原型
2. 记录页原型
3. 详情页原型
4. 历史页原型
5. 我的页原型
6. 页面流转图
7. 首页默认/空/异常状态
8. 记录页未添加/已添加/保存失败状态
