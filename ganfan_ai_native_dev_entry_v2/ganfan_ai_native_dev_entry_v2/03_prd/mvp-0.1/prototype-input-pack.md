# MVP 0.1 原型设计输入包

## 1. 产品名称

干饭

## 2. 一句话定位

AI 饮食决策 App，帮助用户记录饮食、判断当天状态，并给出下一餐建议。

## 3. 视觉要求

- Notion 风格
- 干净克制
- 移动端优先
- 信息层级清楚
- 低饱和
- 少装饰
- 决策导向

## 4. 页面清单

1. 首页
2. 记录页
3. 饮食详情页
4. 历史页
5. 我的页

## 5. 首页模块顺序

1. 顶部问候
2. 今日状态卡片
3. 剩余热量
4. AI 下一餐建议
5. 三餐记录卡片
6. 快速记录按钮

## 6. 记录页模块顺序

1. 餐次选择
2. 食物输入
3. 已添加食物列表
4. 热量估算
5. 保存按钮

## 7. 详情页模块顺序

1. 餐次标题
2. 总热量
3. 食物列表
4. 营养结构
5. AI 简评
6. 编辑/删除

## 8. 历史页模块顺序

1. 日期选择
2. 每日总摄入
3. 餐次记录列表
4. 空状态

## 9. 我的页模块顺序

1. 用户资料
2. 当前目标
3. 每日热量目标
4. 设置入口

## 10. 输出要求

原型必须包含：

- 页面结构
- 模块顺序
- 关键交互
- 空状态
- 错误状态
- 保存成功状态
