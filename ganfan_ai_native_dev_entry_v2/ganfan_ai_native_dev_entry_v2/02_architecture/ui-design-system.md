# UI Design System

## 1. 风格定位

关键词：

- 干净
- 克制
- Notion 风格
- 信息层级清楚
- 移动端优先
- 决策导向

## 2. 设计原则

1. 少装饰，多结构
2. 先展示状态，再展示细节
3. 操作入口必须明确
4. 所有颜色服务状态，不做花哨表现
5. 卡片之间留足间距

## 3. 色彩 Token

```ts
colors = {
```

```ts
  xs: 4,
  sm: 8,
  md: 12,
```

