# 工程入场决策

## 结论

不直接开发完整 MVP。

先做 MVP 0.0：工程底座和自动化更新链路。

## 为什么

如果现在直接做 MVP，后面会继续出现：

- 仓库结构乱
- UI 规则乱
- AI 任务边界乱
- 热更新补不上
- Android/iOS 适配返工
- 自动化部署东补西补

## 进入业务开发的门槛

只有完成以下事项，才进入 MVP 0.1：

- GitHub 仓库
- AGENTS.md
- Expo 工程
- Android preview 包
- EAS Update preview channel
- CI
- 基础页面壳
- 原型确认
- PRD V1 回填
