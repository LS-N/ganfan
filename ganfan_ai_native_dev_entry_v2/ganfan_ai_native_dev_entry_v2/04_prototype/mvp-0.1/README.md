# MVP 0.1 原型产物目录

## 目录定位

本目录用于存放 MVP 0.1 的原型产物，不替代 PRD。

职责边界：

- `03_prd/`：定义需求、页面规则、验收标准。
- `04_prototype/`：存放原型图、页面流转图、关键状态图、已确认设计稿。
- `05_ai-coding/`：存放给 Codex 的开发任务。

## 当前阶段

当前原型尚未确认。

在进入 MVP 0.1 Coding 前，必须完成：

1. 首页原型确认
2. 记录页原型确认
3. 饮食详情页原型确认
4. 历史页原型确认
5. 我的页原型确认
6. 页面流转确认
7. 关键状态确认

## 文件说明

- `page-flow.md`：页面流转与核心路径。
- `prototype-assets.md`：原型图、设计稿、截图、Figma 链接记录。
- `confirmed-screens.md`：确认后的页面说明，用于回填 PRD V1。

## 铁律

没有原型确认，不进入 MVP 0.1 Coding。
