# 干饭 Ganfan

AI 饮食决策 App。

## 产品定位

帮助用户完成饮食记录、状态判断和下一餐决策建议。

## 当前目标

先搭建工程底座，再进入 MVP 0.1。

## 开发入口

1. 阅读 `START_HERE.md`
2. 阅读 `AGENTS.md`
3. 执行 `05_ai-coding/codex-bootstrap-prompt.md`
